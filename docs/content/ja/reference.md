# リファレンス

livt には別冊のマニュアルはありません。知りたいことは次の場所にあります。

## コマンドの使い方

`livt <command> --help`

## ファイルの書き方、形式、変更のルール

ファイルを書く skill（[plugins/](https://github.com/boykush/livt/tree/main/plugins)）

## エージェントからの読み方と、引用の仕方

`livt mcp` — サーバーが自分のツールとリソースを説明します

## URI が指している先

`livt resolve <uri>`

## livt 自身について合意したルールと、その理由

ライブデモにある livt 自身の[実例マッピング](https://boykush.github.io/livt/demo/)
